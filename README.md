# BREW 1968: a scroll-to-brew milk tea fan concept

Scroll to brew a Vietnamese milk tea layer by layer: tea pours in, milk blooms, pearls drop, the lid snaps on; then pick a flavour. Built by Web Atelier as an unofficial fan concept, not affiliated with or endorsed by Phuc Long. Drink and ingredient images are AI-generated illustrations; pour effects rendered in EffectCraft, cut-outs in PhotoCraft. Nothing is sold here.

- `site/`: static page (canvas + GSAP ScrollTrigger + Lenis from CDN), served by nginx (`Dockerfile`, `nginx.conf`, `/healthz`).
- Live: https://trasua.yan.io.vn (noindex).
- Source of truth for edits: `video-plans/web-atelier/phuclong/site`, copied here before each deploy.
